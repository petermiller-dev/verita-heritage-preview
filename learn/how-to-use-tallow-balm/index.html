How to use tallow balm

Start smaller than you think

For a patch of dry skin, start with a small dab. Warm it between clean fingertips for a moment, then smooth a thin layer over the area. Add a little more if you need it.

Try it after washing your hands

Pat your hands dry and work a thin layer over dry knuckles and cuticles. For elbows, smooth a little over each one after a shower. Follow the directions on your jar.

Pick a scent you’ll enjoy using

If you prefer a floral scent, look for our Rose Scent. If you prefer to skip added scent, check the current listing for the unscented option and read the full label.
